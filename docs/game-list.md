# 作品一覧の表示順と絞り込み

- 一押し作品（`star: true`）は `featured_order` 順を維持します。
- その他の作品は `published_on`（YYYY-MM-DD）の新しい順です。同日は登録 ID の大きい順です。
- 既存作品の掲載日は、詳細ページを最初に追加した Git の履歴を使用しています。制作日を確認できた場合は、この日付を更新してください。
- 開発言語のボタンは tags の csharp、cpp、language から生成します。制作形態と言語の条件は併用できます。
- 新規作品を追加するときは掲載日も指定してください。
- テトリスのカバーは紹介用の図案です。実機スクリーンショットではありません。プレイ用の配布 URL は未設定です。
