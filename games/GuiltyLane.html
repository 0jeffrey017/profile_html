Guilty Lane

Dark Adventure Game / Hackathon Work

Overview / 概要

借金を抱えた主人公は、ある企業の「線路管理業務」に雇われる。その作業は、レバーを引いてトロッコの行き先を決めるだけだった。だがその先には、必ず“誰か”がいる──。これは選ぶ者が背負う“罪の軌道”の物語。究極の選択が今始まる。

Game Engine / ゲームエンジン

Platform 調整中

Challenges & Solutions / 問題点と解決方法

Problem / 問題点

複数人開発における、ゲーム内データ構造およびイベント仕様の統一

Solution / 解決策

仕様書の綿密なドキュメント化と定例会議の実施により、認識の乖離やアセットの不整合を徹底的に防止
