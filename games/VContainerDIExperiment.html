VContainer DI Experiment

Architecture Experiment Game

Overview / 概要

純粋なゲームロジックとオブジェクトの依存関係を疎結合に保つため、DIコンテナ「VContainer」を導入した実験的ミニゲームです。

Game Engine / ゲームエンジン

Unity 6000.3.8f1

Production period / 制作期間

2026/5

Responsible part / 担当部分

  • 個人製作（企画・設計・実装の全工程を担当）
Platform PC (Windows, WebGL)
Players Single Player（1人用）
sports_esports

How to Play / 操作方法

Mouse

Challenges & Solutions / 問題点と解決方法

Problem / 問題点

密結合になりがちなシングルトンパターンへの過度な依存からの脱却

Solution / 解決策

VContainerによる依存性の注入（DI）を実践。クラス間の結合度を下げ、テストと再利用が容易な設計を構築
