Space Cat

Action Game / PC

Overview / 概要

実験体として宇宙戦艦に囚われていた猫。突如発生した爆発により、戦艦は崩壊の危機に瀕する。

生身では生きられない残酷な宇宙環境から逃れるため、4つの生存装備を探し出せ。不思議な力を持つ「尻尾」を使いこなし、迫りくる危機を回避して出口を目指す、SFサバイバル・アクション。

Challenges & Solutions / 問題点と解決方法

Problem / 問題点

一回クリアは難しくので、セーブポイントがほしい

Solution / 解決策

Playerの位置、アイテムの詳細をJsonで書き出す、セーブする

Sample Code / サンプルコード

Language: csharp
public class SaveManager : MonoBehaviour
{
        public void SaveDataToJson<T>(string path, T data)
    {
        var s = JsonUtility.ToJson(data, true);
        if (!File.Exists(path))
        {
            File.Create(path).Close();
        }
        using StreamWriter writer = new StreamWriter(path);
        writer.Write(s);
        writer.Close();
        Debug.Log($"save success");
    }

    public T LoadDataFromJson<T>(string path)
    {
        if (File.Exists(path))
        {
            using StreamReader reader = new StreamReader(path);
            var s = reader.ReadToEnd();
            var data = JsonUtility.FromJson<T>(s);
            reader.Close();
            return data;
        }
        return default;
    }
}
