Challenges & Solutions / 問題点と解決方法

Problem / 問題点

難易度が高く一画面でのクリアが困難なため、ゲーム進行度の中断・再開機能（セーブ機能）が必須

Solution / 解決策

プレイヤーの位置座標、獲得アイテムの状態をシリアライズし、JSONファイルとしてローカルに書き出し・読み込みを行うセーブシステムを構築

Problem / 問題点

ワイヤーを用いたスイングアクションの挙動に違和感があり、手触りが理想に届いていない

Solution / 解決策

現段階では完全な解決に至っておらず、物理演算（HingeJoint2Dなど）のパラメータ調整およびベクトル計算の再設計を含め、現在も継続して研究中

Sample Code / サンプルコード

ゲーム内ステートの永続化を担当するSaveManagerの実裝。堅牢なシリアライズ処理の実現
JSONデータセーブシステム
public class SaveManager : MonoBehaviour
{
        public void SaveDataToJson<T>(string path, T data)
    {
        var s = JsonUtility.ToJson(data, true);
        if (!File.Exists(path))
        {
            File.Create(path).Close();
        }
        using StreamWriter writer = new StreamWriter(path);
        writer.Write(s);
        writer.Close();
        Debug.Log($"save success");
    }

    public T LoadDataFromJson<T>(string path)
    {
        if (File.Exists(path))
        {
            using StreamReader reader = new StreamReader(path);
            var s = reader.ReadToEnd();
            var data = JsonUtility.FromJson<T>(s);
            reader.Close();
            return data;
        }
        return default;
    }
}
