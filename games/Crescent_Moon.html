Overview / 概要

東京ゲームショウ2026に出展した、月が照らす異世界の回廊から脱出を目指す2D探索アクションです。プランナー3人・プログラマー5人・2Dデザイナー5人の計13人で、5か月間制作しました。

月を見上げると、プレイヤーの現在位置をもとにマップが再生成されます。敵を倒し、攻撃をかわしながら、変化する回廊を探索します。

私はプログラマー5人のチームでプログラマーリーダーを務め、ゲーム進行とマップ生成、システム間のイベント連携、アセット読み込みを担当しました。状態遷移の競合とマップの更新順序に対する工夫を、課題と対応・コードの各タブで紹介しています。

実装の見どころ

演出・読み込み中に重なる状態遷移をキューで順に処理。マップ再生成では、表示の更新完了を待って経路・配置の更新へ進める構成にしました。

課題と対応 / Challenges & Solutions

Problem / 問題点

演出やシーン読み込み中に状態遷移が重なり、進行処理が競合する問題がありました。

Solution / 解決策

遷移要求をキューで順に処理し、同じ状態への重複要求をまとめます。OnExitとOnEnterの完了を待ち、終了判定とキャンセル処理も組み込みました。

Problem / 問題点

マップ再生成時に、表示・敵の経路・アイテム配置の更新順序を揃える必要がありました。

Solution / 解決策

R3でマップの変更を受け取り、表示更新の完了後にNavMesh・アイテム・日輪草・出口の生成イベントを順番に配信します。

Problem / 問題点

多くのシステムを直接参照すると、変更の影響が広がります。

Solution / 解決策

VContainerのInstallerで依存関係の登録を機能ごとに分け、型付きEventBrokerで連携します。非同期ハンドラーの完了はUniTask.WhenAllで待ち、購読解除にはIDisposableを使います。

コード抜粋 / Code Samples

状態遷移の要求をキューから一つずつ取り出し、終了処理と開始処理の完了を待ちます。各要求には、完了・例外・キャンセルを通知します。
遷移キューによる非同期 FSM（コア処理）
/*
 * Crescent_Moon / 非同期 FSM のコア処理（抜粋）
 * TransitionRequest は完了・例外・キャンセルを待機者へ通知する要求オブジェクト。
 */

private async UniTask ProcessTransitionQueueAsync(CancellationToken token)
{
    try
    {
        // 要求を一つずつ処理し、非同期の状態遷移が重なるのを防ぐ。
        while (_transitionQueue.Count > 0)
        {
            token.ThrowIfCancellationRequested();

            TransitionRequest request = _transitionQueue.Dequeue();
            _activeRequest = request;
            if (_transitionQueue.Count == 0)
            {
                _lastQueuedRequest = null;
            }

            try
            {
                // 終了処理と開始処理が完了してから、待機者へ完了を通知。
                await TransitionTo(request.State, token);
                request.Complete();
            }
            catch (OperationCanceledException)
            {
                // 中断時は処理中・待機中の要求をまとめてキャンセル。
                request.Cancel(token);
                CancelPendingRequests(token);
                throw;
            }
            catch (Exception exception) when (exception is not OperationCanceledException)
            {
                InvalidOperationException transitionException = new(
                    $"[GameStateMachine] Transition to {request.State} failed.",
                    exception);
                request.Fail(transitionException);
                CancelPendingRequests(token);
                throw transitionException;
            }
            finally
            {
                _activeRequest = null;
            }
        }
    }
    finally
    {
        _isProcessingQueue = false;

        if (_transitionQueue.Count > 0 && !token.IsCancellationRequested)
        {
            _isProcessingQueue = true;
            ProcessTransitionQueueAsync(token).ForgetSafely();
        }
    }
}

private async UniTask TransitionTo(EGameState nextState, CancellationToken token)
{
    // 遷移中はゲームプレイを停止し、旧状態の終了を待つ。
    _pauseService.SetPaused(true);

    if (_currentState != null)
    {
        await _currentState.OnExit(token);
    }

    _currentState = _stateFactory.Create(nextState);
    _currentStateType = nextState;

    // 新状態の初期化・演出が完了してからプレイ可能な状態だけ再開。
    await _currentState.OnEnter(token);
    _pauseService.SetPaused(nextState is not EGameState.MainGame and not EGameState.Tutorial);
}
マップの変更を受け取り、表示、移動経路、アイテム配置の順に更新を進めます。月を見上げたときは、プレイヤーの現在位置を基準に新しいマップを生成します。
R3 とイベント通知によるマップ更新（コア処理）
/*
 * Crescent_Moon / マップ更新と月イベントの連携（抜粋）
 * 購読は AddTo でまとめて保持し、Dispose 時に解除する。
 */

private void Bind()
{
    // Model の変更を購読し、View の更新完了後に各システムへ通知。
    _mapGeneratorModel.CurrentMap
        .SubscribeAwait(async (v, ct) =>
        {
            await _mapViewer.HandleMapView(v);
            // マップ表示 → 経路再構築 → アイテム配置の順序を揃える。
            await _gameEventBroker.Publish(new MapNavMeshGenerationEvent(), ct);
            await _gameEventBroker.Publish(new MapItemGenerationEvent(v), ct);
            await _gameEventBroker.Publish(new MapSunFlowerGenerationEvent( _mapGeneratorModel.CurrentSunFlowerMap.CurrentValue), ct);
            await _gameEventBroker.Publish(new MapTempleExitGenerationEvent( _mapGeneratorModel.CurrentTempleExitMap.CurrentValue), ct);
            // 新しいマップ通知が来たら、前の購読処理のキャンセルを要求。
        }, AwaitOperation.Switch).AddTo(_Disposable);
    
    _gameEventBroker
        .Subscribe<SunFlowerCollectedEvent>(HandleSunFlowerCollectedEvent)
        .AddTo(_Disposable);
    
    _gameEventBroker
        .Subscribe<GameStartEvent>(HandleGameStartEvent)
        .AddTo(_Disposable);
    _gameEventBroker
        .Subscribe<GazingMoonEvent>(HandleGazingMoonEvent)
        .AddTo(_Disposable);
}

private async UniTask HandleGazingMoonEvent(GazingMoonEvent e, CancellationToken token)
{    
    await _gameEventBroker.Publish(new MapGenerationStartedEvent(), token);
    // 月イベントに含まれる現在位置を、新しいマップの生成基準にする。
    MapCell player = _mapGeneratorModel.GetMapCellByPosition(e.X,e.Y);
    await _mapGeneratorModel.StartGeneration(player);
}
イベントの型ごとに購読者を管理し、非同期処理をまとめて待ちます。購読を解除するためのIDisposableも返します。
UniTask による型付きイベント配信（コア処理）
/*
 * Crescent_Moon / 型付き非同期 EventBroker のコア処理
 * _events は Dictionary<Type, Delegate>、Subscription は Dispose で解除処理を実行。
 */

public async UniTask Publish<T>(T message,CancellationToken token) where T : IEvent
{
    // 型ごとに配信先を取得。発行側は購読者の具体的なクラスを知らなくてよい。
    if (!_events.TryGetValue(typeof(T), out Delegate eventDelegate))
    {
        Debug.LogWarning($"[EventBroker] No one is listening to {typeof(T).Name}");
        return;
    }

    Delegate[] invocationList = eventDelegate.GetInvocationList();
    if (invocationList.Length == 1)
    {
        await ((Func<T, CancellationToken, UniTask>)invocationList[0])(message, token);
        return;
    }

    var tasks = new UniTask[invocationList.Length];
    for (int i = 0; i < invocationList.Length; i++)
    {
        tasks[i] = ((Func<T, CancellationToken, UniTask>)invocationList[i])(message, token);
    }
    // 全ハンドラーの完了を待つため、呼び出し側も await で順序を制御できる。
    await UniTask.WhenAll(tasks);
}

public IDisposable Subscribe<T>(Func<T,CancellationToken,UniTask> action) where T : IEvent
{
    Type type = typeof(T);

    _events[type] = _events.TryGetValue(type, out var existing) ? Delegate.Combine(existing, action) : action;
    // 返した購読オブジェクトを Dispose すると、このハンドラーだけ解除する。
    return new Subscription(() =>
    {
        if (_events.TryGetValue(type, out Delegate current))
        {
            Delegate removed = Delegate.Remove(current, action);
            if (removed == null)
            {
                _events.Remove(type);
            }
            else
            {
                _events[type] = removed;
            }
        }
    });
}
